# WhatNow? roadmap

WhatNow? is an early-stage, public MVP. The roadmap is intentionally small so
that reliability, privacy, and clear user outcomes stay ahead of feature count.

## Current focus

- Keep document understanding, translation, and document workspace flows reliable.
- Improve mobile accessibility and keyboard support.
- Expand automated regression coverage for uploads, quotas, reminders, and billing.
- Make security and privacy behavior easy to audit before adding integrations.

## Next priorities

- Improve observability for failed analyses without logging document contents.
- Add more public examples and contributor documentation.
- Continue performance work for large documents and low-bandwidth devices.

Suggestions and pull requests are welcome through the public contribution flow.
