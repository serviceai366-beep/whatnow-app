# Support

For questions about using the hosted WhatNow? application, use the in-app
Support section. That keeps account-specific conversations visible only to the
user and authorized maintainers.

Use GitHub Issues for a reproducible public software defect or a focused,
non-confidential feature proposal. Before posting, remove names, addresses,
document contents, screenshots with personal data, payment details, and all
credentials.

Do not use GitHub Issues for account recovery, billing disputes, private
documents, or security vulnerabilities. Follow [SECURITY.md](SECURITY.md) for
security reports.
