# WhatNow? brand

The WhatNow? name, logo, and visual identity are project branding. The Apache
License 2.0 covers the source code only and does not grant permission to use
the WhatNow? name or logo for a fork, hosted service, or product in a way that
could imply endorsement, affiliation, or official status.

Forks may describe compatibility with WhatNow? accurately, but should choose a
distinct product name and remove the WhatNow? logo unless the maintainer gives
separate written permission.
